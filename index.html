      Laravents

      Eloquent for events. Modules for Laravel. Commands, queries and events with conventions, attributes and an outbox, so modules talk through a public API and never through each other's models.Eloquent para eventos. Módulos para Laravel. #[Authorize]
#[Transactional]
#[Expose]
public function give(GiveNickname $command, #[CurrentUser] Authenticatable $actor): int
{
    return Nickname::query()->create([

        'member_id' => $command->memberId,
        'nickname' => $command->nickname,
    ])->id;
}
